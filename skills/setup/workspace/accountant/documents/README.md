# Documents — the actual files

Naming: `YYYY-MM-DD_<ID>_<counterparty>_<short-title>.<ext>` (e.g.
`2027-02-01_INV-O-2027-0001_ExampleCo_feb-subscription.pdf`). Never rename or delete a filed
document; a corrected version gets a new file with `_v2`. Folders:

| Folder | What |
|---|---|
| corporate/ | charter, registration extract, founder decisions, share capital proof |
| contracts/ | signed contracts and amendments |
| invoices-out/ | issued invoices, e-invoice exports, signed acts |
| invoices-in/ | supplier invoices, foreign subscription receipts |
| bank/ | bank statements |
| payroll/ | employment / contractor agreements, payslips, timesheets |
| filings/ | prepared and submitted returns, submission receipts |
| authority-letters/ | any letter, notice, request or decision from the tax authority or another authority |
| receipts/ | cash/card receipts for small expenses |
